# Stack
- TypeScript + React 19 + TanStack Start file routes; Cloudflare Vite plugin builds Worker SSR. Keep cloudflare, Tailwind, TanStack Start, React plugin order in vite.config.ts.
- npm/package-lock.json. PostgreSQL via postgres; Clerk handles identity; ADMIN_USER_IDS must hold exactly two distinct IDs.
- Tailwind v4 uses @tailwindcss/vite and src/styles.css; shadcn Base UI source in src/components/ui. @ alias maps src in both Vite and TypeScript.
